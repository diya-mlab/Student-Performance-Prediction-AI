# 🎓 Student Performance Prediction AI

### Intelligent Academic Performance Analysis

An AI/ML-based web application that predicts a student's examination marks using daily study hours and previous examination marks.

## 🚀 Project Overview

Student Performance Prediction AI uses Machine Learning to estimate academic performance based on student study habits and previous results.

The application provides a simple and interactive interface where users can enter student details and receive predicted examination marks.

## ✨ Features

- Predict examination marks using Machine Learning
- Enter daily study hours
- Enter previous examination marks
- View predicted performance category
- Receive personalized study suggestions
- Simple and interactive web interface

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Gradio

## 🤖 Machine Learning Model

**Algorithm:** Linear Regression

**Input Features:**
- Daily Study Hours
- Previous Examination Marks

**Output:**
- Predicted Examination Marks

## 💻 How to Run the Project

1. Clone this repository:

   `git clone https://github.com/diya-mlab/Student-Performance-Prediction-AI.git`

2. Open the project folder.

3. Install the required libraries:

   `pip install -r requirements.txt`

4. Run the application:

   `python app.py`

## 📊 Dataset

This project currently uses a small sample dataset for demonstration and learning purposes.

Predictions should not be treated as actual examination results.
